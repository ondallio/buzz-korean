# 한국어 용어

| 원문 | 번역 | 기준 |
| --- | --- | --- |
| Community | 커뮤니티 | 사용자 커뮤니티 이름은 보존 |
| Solo | 솔로 | 공유 가능하므로 비공개/개인 채널로 단정하지 않음 |
| Team | 팀 | 원본 저장 값은 보존 |
| Channel | 채널 | 채널명은 보존 |
| Message / thread / reply | 메시지 / 스레드 / 답글 | 버튼은 짧게 |
| Direct message | 다이렉트 메시지 | 좁은 UI에서는 DM |
| Activity | 활동 | 현재 Inbox plugin의 실제 표시 이름 |
| Agent / workflow | 에이전트 / 워크플로 | 사용자 이름·ID 보존 |
| Project / repository | 프로젝트 / 저장소 | git 명령과 경로 보존 |
| Issue / pull request | 이슈 / PR | git ref와 API 필드 보존 |
| Plugin / model / tool | 플러그인 / 모델 / 도구 | 제품명·모델 ID 보존 |
| Relay | 릴레이 | 서버 주소 보존 |
| Community admin / relay operator / moderator | 커뮤니티 관리자 / 릴레이 운영자 / 중재자 | 서로 다른 권한이며 role 저장 값은 보존 |
| Focus / terminal | 집중 모드 / 터미널 | 자동 상태 데이터와 명령은 보존 |
| Settings / appearance | 설정 / 화면 설정 | 선택값·내부 route 보존 |
| Search / send / save | 검색 / 보내기 / 저장 | 버튼 |
| Cancel / close / back | 취소 / 닫기 / 뒤로 | 버튼 |
| Retry / delete / remove | 다시 시도 / 삭제 / 제거 | 실제 행위 구분 |
| Sign in / sign out | 로그인 / 로그아웃 | 비밀 키 자체는 표시·번역하지 않음 |

안내·오류는 자연스러운 존댓말로 씁니다. 변수가 들어간 문장은 전체를 번역합니다.
사용자 작성 메시지·채널명·파일명·코드·명령어·이벤트 종류·저장 값은 번역하지 않습니다.
