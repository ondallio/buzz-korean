# Buzz 데스크톱 한글화 전달 기록

이 폴더의 데스크톱 소스에 한국어·영어 선택, OS 언어에 따른 첫 실행, 설정 저장, 화면 문구·접근성 이름·날짜·숫자·앱 소유 알림과 네이티브 메뉴 언어 전달을 구현했습니다. 언어 변경으로 메시지 초안, 입력·동의·저장소·모델 선택, 에이전트 원문 이벤트와 전송 소유권을 잃는 회귀도 수정했습니다. 사용자 메시지·이름·파일·코드·프로토콜 값은 보존합니다.

구현과 자동 검증·독립 리뷰를 마쳤습니다. **전체 CI 성공, 네이티브 IME 확인, 사용자 직접 확인은 완료 처리하지 않습니다.** 아래 결과와 제한을 함께 보세요. PR·커밋·병합·배포는 하지 않았습니다.

카탈로그 키 수는 번역 완료율이 아닙니다. 정적 검사 밖의 생산자·문장 슬롯·동적 상수·실제 화면도 따로 감사했습니다. [범위 감사](FINAL-COVERAGE.md), [메모/효과 감사](memo-effect-audit.json), [검사 영수증과 로그](verification/results.json)를 함께 확인하세요. 화면 예: [언어 설정](verification/settings.png), [프로젝트](verification/projects.png), [워크플로](verification/workflow.png), [이모지 선택기](verification/emoji-picker.png). 브라우저 증거는 `desktop/test-results/verify-desktop/ko-final/`에 있습니다. Mock 경계 위의 실제 React·라우팅·저장·키보드 조작을 검사했으며 실제 릴레이 동작의 증거는 아닙니다. 확대 검사는 CSS 150% 배율이며 네이티브 확대가 아닙니다.

`just ci`는 현재 소스에서 실제 실행했습니다. 모바일 의존성이 없어 멈춘 첫 실행은 잠금 버전을 유지한 `flutter pub get --enforce-lockfile`로 복구했습니다. 이후 포맷 1,023개 파일 변경 0·분석 이상 없음까지 통과했고 최종 실행은 Git 차이 검사에서 멈췄습니다. 원본 Git 이력 없이 저장소를 임의로 초기화하거나 원격에 연결하지 않았습니다. 이 때문에 전체 `just ci` 통과를 주장할 수 없습니다. 중단 뒤의 데스크톱 테스트·빌드·네이티브 검사와 웹 빌드는 별도로 실행했습니다. 전체 Rust `just test-unit`과 모바일 테스트는 이 작업에서 별도로 실행하지 않았습니다.

## 실행 방법

macOS 터미널에 다음 세 줄을 입력하세요. 첫 실행은 에이전트 실행 도구도 빌드하므로 시간이 걸릴 수 있습니다.

```sh
cd /Users/stan/orca/buzz-main-kor
. ./bin/activate-hermit
just desktop-standalone
```

정상 결과는 **Buzz Dev** 창이 열리는 것입니다. 평소 사용하는 커뮤니티와 계정으로 연결하세요. 앱의 프로필 메뉴 → 설정 → 화면 설정 → 언어에서 `한국어` 또는 `English`를 선택할 수 있습니다. 처음 실행한 기기는 OS가 한국어이면 한국어를 선택하고, 한 번 저장한 선택은 OS 언어보다 우선합니다. 이 일반 네이티브 실행 명령을 이번 자동화에서 끝까지 조작한 것으로 계산하지 않았습니다.

## 직접 확인할 순서

1. 언어를 English → 한국어로 바꿔 버튼·메뉴·설정·단축키 제목을 확인하세요. 앱을 종료하고 위 명령으로 다시 열었을 때 한국어가 유지되어야 합니다.
2. 메시지를 입력한 상태로 설정에 다녀오고 언어를 바꿔 보세요. 초안이 그대로 남아야 합니다. 전송한 메시지·채널명·파일명은 입력한 그대로여야 합니다.
3. 실제 네이티브 앱에서 한글 입력기를 켜세요. 글자 **조합 중 Enter**는 메시지를 보내면 안 됩니다. 조합 완료 후 Enter는 한 번 전송하고, Shift+Enter는 줄만 바뀌어야 합니다. **이 IME 항목은 아직 미검증입니다.**
4. 검색, 채널 우클릭 메뉴, 설정 저장, 에이전트·프로젝트·워크플로를 차례로 열어 보세요. 저장소·모델을 선택한 상태도 언어 변경으로 초기화되면 안 됩니다.
5. 창을 좁히고 앱의 글자 크기/확대를 조절해 보세요. 버튼을 읽고 누를 수 있어야 합니다. 실제 메뉴 막대·트레이·알림의 앱 소유 문구도 확인해 주세요.

사용자 직접 확인은 **대기**입니다. 실제 네이티브 IME·메뉴·시스템 알림 전달·네이티브 확대·실제 스크린리더, 릴레이/관리 권한의 모든 분기와 내부 전용 기능은 자동화로 완료 처리하지 않았습니다. 알 수 없는 서버·라이브러리 진단은 원문 데이터로 보존하며 한국어 번역 완료 수에 포함하지 않습니다.

- 원본 버전은 패키지 기준 `0.5.28`이며 정확한 upstream 커밋은 확인할 Git 메타데이터가 없습니다.

- [번역 구조](../../desktop/src/shared/i18n/README.md), [용어표](GLOSSARY.md), [계획](PLAN.md)을 읽고 이어가세요. 옛 배치 목록과 현재 누락 수를 합산하지 마세요.
